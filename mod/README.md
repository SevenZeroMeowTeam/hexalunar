## 武器与弹道

三把玩家武器都有**拉弦/举枪动作、有效射程与超距下坠**，并在第一人称下明显放大，手感更接近真实枪械。

| 武器 | 操作 | 有效射程 | 射程内重力 | 特点 |
|---|---|---|---|---|
| 复合弓 | 按住右键瞄准蓄力（带拉弦动画），左键按当前蓄力击发 | 34 格 | 0.028 | 穿透箭，蓄力满可贯穿多个目标 |
| 战术十字弩 | 按住右键开镜瞄准（**4 倍镜**），左键射击，可按住连发 | 40 格 | 0.022 | 举弩即持续开镜，遮手自动隐藏；拉弦/装填为骨骼动画（**弓臂拉弦时向内收缩**，r63）；**外形 = 参考网格 `十字弩_v2` 那把现代复合弩**（r61 表面体素化，824 方块） |
| AKM 突击步枪 | 按住右键瞄准，左键全自动射击，R 键装填（空仓自动装填） | 60 格 | 0.006 | **子弹 10 点伤害**（5 颗心），30 发弹匣，枪口抖动与后坐；**顶部导轨可装红点 / 4 倍镜**；第一人称**双手持枪** |

**光学瞄具（AKM，新增）**：潜行 + 右键装/拆。**红点瞄准镜**只将屏幕正中画一个红点、枪身照旧可见；
**4 倍瞄准镜**与十字弩一致整屏开镜（视野 ×1/4 + 圆形镜筒 + 十字分划）。
两种瞄具的光轴参照点写死在 `weapon/WeaponMount.java`，举枪时会自动顶到屏幕正中。

**弹道规则**：弹头在有效射程内几乎平直；飞越有效射程后，每 tick 追加的下坠量按「超出比例的平方」增长（约 2.25 倍射程后封顶）——想打得准，就得把目标留在有效距离之内。实现见 `weapon/Ballistics.java`。

**修复说明（r15）**：换弹/检视动画直接读取原版手持物品的姿态参数驱动，AKM 现在垂直握在手中而不再斜挂，弩与弓的拉弦姿态也与持握模型对齐。

## 弹药与弹药盒

弹药本身：

- `弩箭`（crossbow_bolt）— 十字弩弹
- `复合弓箭`（compound_arrow）— 复合弓弹，另有 `尸毒箭`（poison_arrow）变体
- `7.62x39mm 子弹`（ammo_762）— AKM 弹

**弹药盒**（r13 起区分三类，右键收纳背包中同类弹药，装填时优先从盒内取用）：

- `弩箭弹药盒` — 只吃弩箭
- `箭矢弹药盒` — 只吃复合弓箭
- `步枪弹药盒` — 只吃 7.62 子弹
- `创造弹药箱` — **放在物品栏（快捷栏 / 背包 / 副手）里就生效**：三把武器无限供弹，不用手持、不用切弹种

三类弹药盒虽然外观相似，但**合成配方互不相同**（中心格放对应的弹药本体），物品也是三个独立注册 ID + 各自 `AmmoType`，因此绝不混用。

## 投掷物：碎片手雷与震爆弹

两枚手雷共用一套拔销机制（`GrenadeItem` + `GrenadeEntity`）：

1. **按住右键 1 秒**拔出保险销；中途松手 → 保险销自动弹回，完全安全；
2. 拔销后引信 5 秒倒计时（HUD 实时显示）；压杆还被手压着时，**再按住右键 1 秒可把保险销插回去拆雷**；
3. **左键丢出**，出手瞬间压杆/击针自然脱落，落地滚动后爆炸；
4. 攥在手里超过 5 秒 → **掌心自爆**。

| 手雷 | 效果 |
|---|---|
| 碎片手雷 | 范围约 6.5 格的原版爆炸（威力 3.5，TNT 为 4.0），破片伤害；方块破坏跟随 `mobGriefing` 规则 |
| 震爆弹 | 半径 9 格内生物 **眩晕 + 致盲** 数秒，基本不造成伤害；隔不透明方块效果大幅衰减 |

## 六相月灾系统

夜晚月相按周期轮转（`moon/MoonPhase.java`），六种灾月各自有**专属的月亮颜色与天空颜色**，效果也不同：

| 月相 | 月亮颜色 | 天空（天顶 / 地平线） | 效果 |
|---|---|---|---|
| 血月 | 红 `#FF4A38` | `#1C0608` / `#521114` | 尸潮数量翻倍 |
| 蓝月 | 淡青蓝 `#AECBFF` | `#06101F` / `#143A6E` | 僵尸速度提升 |
| 黄月 | 金 `#FFD35E` | `#141005` / `#453512` | 猎杀掉落增益 |
| 超级血月 | 亮红 `#FF6E52` + 大光晕 | `#28070B` / `#6E1616` | 长夜漫漫，尸潮无休 |
| 超级蓝月 | 冰蓝 `#D2E8FF` + 大光晕 | `#08142E` / `#1C4A88` | 亡者速度超出想象 |
| 超级黄月 | 淡金 `#FFE9A0` + 大光晕 | `#1C1608` / `#57431A` | 天上落下了什么东西？（空投巨箭） |

月升时全服弹出标题与提示，天空与月盘同时换上该相的颜色（实现在 `client/MoonSkyRenderer.java`，
在 `Stage.AFTER_SKY` 自己画天穹与月盘；配色预览：`python tools/_moonsky_mock.py`）。

## 变异亡者

月夜刷新的 6 种变异怪（`entity/mob/`）：

- **自爆尸** Bomber Zombie — 贴脸引爆
- **喷吐尸** Archer Zombie — 远程喷吐尸毒箭
- **蛮兵尸** Barrel Zombie — 高血量冲脸
- **巨尸** Giant Zombie — 巨型体型、重击退
- **突袭骷髅** Rusher Skeleton — 高速逼近的弓手
- **剧毒骷髅** Toxic Skeleton — 射出带尸毒的箭

## 解毒与尸毒

- **尸毒**（Corpse Poison）：被变异亡者击中概率感染，持续掉血；
- **尸毒萃取剂**：从剧毒骷髅/喷吐尸掉落；
- **尸毒瓶**：尸毒萃取剂 + 玻璃瓶 → 2 瓶，投掷后在落点炸开一团尸毒雾；
- **强效解毒剂**：萃取剂 + 蜂蜜瓶 + 糖 合成，饮用清除尸毒。

## 操作一览

| 按键 | 功能 |
|---|---|
| 右键（按住） | 弓：蓄力瞄准 / 弩：开 4 倍镜 / AKM：据枪瞄准 / 手雷：拔销或插回保险销 |
| 左键 | 射击 / 丢出手雷 |
| `R` | AKM 装填（可在 设置 → 按键绑定 → 六相月灾 中修改） |
| 潜行 + 右键 | **AKM：装/拆瞄具**（副手拿瞄具 = 装上，空手 = 拆下） |

## 安装

1. 安装 Minecraft 1.20.1 + Forge 47.x（推荐 47.4.0）；
2. 把 **GeckoLib 4.8.4**（`geckolib-forge-1.20.1-4.8.4.jar`）和 `hexalunar_calamity-1.0.0-r68.jar` 一起放进 `.minecraft/mods/`；
3. 启动游戏，选择 Forge 1.20.1 实例即可（**缺 GeckoLib 会直接加载失败**）。

从旧版本升级时直接替换 jar 即可，无需删世界数据。

    弦与凸轮盘的 pivot 就在弓臂梢上，所以它们跟着弓臂平移同样的位移，弦不会脱开；

  - **修「AKM 射击时手臂上下晃、不平行」**：手臂读的 `GunFrame` 被**图标那一遍**（GUI display）写了空值 ——
    手臂在 `RenderHandEvent` 里比物品**先**画、读上一帧的捕获，r62 的门控让图标那遍写入一套
    「无举枪、无后坐」的值 ⇒ 枪动、手不跟着（瞄准时垂直错位最明显）。现在 frame **只在手持语境捕获**
  - **修「物品栏里 AKM 发射时还是往后移动」**：r62 只门控了「后坐」，而 `firing()` / 换弹进度是
    **本地玩家的全局状态**，非手持语境里动画推在 `move` 上的 Z（以及弹匣下坠、弩弦回拉、抛壳）照样生效
    ⇒ 现在非手持语境直接走 `staticPose()`（只画一帧静态姿态），弩的箭按被渲染那把弩自己的 `cockedNow` 决定

- **r62** — 后坐只前后、物品栏图标不再跟着动、换弹稳定：
  - **位移只留 Z（沿枪管前后）**：fire 动画自带的 +0.15px Y（上下）、reload 的 −1.2px / +7°
    全部收掉 —— 用户要求「只前后动、不上下动」；AKM 1.35px / 弩 0.95px 纯后拖，冲量衰减后自己滑回去（十字弩同理）
  - **镜头反馈只留给开火**：`camera` 骨骼只在 `firing()` 时叠到视角上，换弹 / 拉栓（含换完弹那一下）镜头稳定，
    不再「换完弹再上下动一下」
