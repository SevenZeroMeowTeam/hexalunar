# 六相月灾 HexaLunar Calamity

一款 Minecraft **1.20.1 / Forge 47.x** 近战-枪械混合生存模组：六种月相轮流降灾、变异亡者成群来袭，同时给玩家一套从复合弓、十字弩到 AKM 与 **AWP 栓动狙击枪**的火力升级路线。

- 当前版本：**1.0.0-r110**
- Mod ID：`hexalunar_calamity`
- 构建产物：`build/libs/hexalunar_calamity-1.0.0-r110.jar`
- 依赖：Forge 47.4.0 + **GeckoLib 4.8.4**（武器骨骼模型的运行前置，必须装）

## 武器与弹道

六把玩家武器都有**拉弦/举枪动作、有效射程与超距下坠**，并在第一人称下明显放大，手感更接近真实枪械。

| 武器 | 操作 | 有效射程 | 射程内重力 | 特点 |
|---|---|---|---|---|
| 复合弓 | 按住右键瞄准蓄力（带拉弦动画），左键按当前蓄力击发 | 34 格 | 0.028 | 穿透箭，蓄力满可贯穿多个目标 |
| 战术十字弩 | 按住右键开镜瞄准（**4 倍镜**），左键射击，可按住连发 | 40 格 | 0.022 | 举弩即持续开镜，遮手自动隐藏；拉弦/装填为骨骼动画（**弓臂拉弦时向内收缩**，r63）；**外形 = 参考网格 `十字弩_v2` 那把现代复合弩**（r61 表面体素化，824 方块） |
| AKM 突击步枪 | 按住右键瞄准，左键全自动射击，R 键装填（空仓自动装填） | 60 格 | 0.006 | **子弹 10 点伤害**（5 颗心），30 发弹匣，枪口抖动与后坐；**顶部导轨可装红点 / 4 倍镜**；第一人称**双手持枪** |
| **AWP 栓动狙击枪** | 按住右键抵肩开 **8 倍镜**，左键击发，`R` 键换弹匣 | **96 格** | **0.004** | **.338 单发 24 点伤害**（12 颗心，一枪基本带走），**5 发弹匣 + 膛内 1 发**；每发后**自动拉栓抽壳抛壳**（拉机柄抬 **88°**、枪机后退 **3.4px**）；第一人称**双手：左手托护木、右手拉栓**；第一人称持枪与 AKM 同一套规则（`move` 骨骼不做任何额外旋转） |
| **Kar98k 栓动步枪**（r105 新增） | 按住右键抵肩开 **4 倍镜**，左键击发，`R` 键**压桥夹**换弹 | **96 格** | **0.004** | **.338 弹**（与 AWP 共用，伤害/弹道同一档）；木托长枪 + 下弯拉机柄 + **自带 4 倍镜筒**；**5 发内置弹仓 + 膛内 1 发**，每发后自动拉栓抛壳（拉机柄抬 **64°**、枪机后退 **2.6px**）；**没有可拆弹匣** —— 换弹时左手抬到机匣左上方压桥夹；目前**只能在创造模式「六相月灾」页签取用** |
| **莫辛-纳甘 M91/30**（r106 新增） | 按住右键抵肩开 **4 倍镜**（潜行 + 右键拆镜换机瞄），左键击发，`R` 键**一发一发压弹** | **84 格** | **0.005** | **7.62x59mm 单发 26 点伤害**（13 颗心，**爆头 ×1.85**）· **独立弹种**（与 AKM 的 7.62x39、AWP 的 .338 **都不通用**）；**5 发固定弹仓**（无弹匣）：开栓 → **每发 12 tick 一发一发压进去** → 关栓上膛，超过 35% 进度被打断时那一发有 **30%** 概率掉地；**拉栓自动抽壳 → 抛壳 → 再上膛**（18 tick ≈ 0.85 s）；木托 + 发蓝钢 + 顶部导轨，**枪管加长**（整枪 1.40 格） |

**光学瞄具（AKM，新增）**：潜行 + 右键装/拆。**红点瞄准镜**只将屏幕正中画一个红点、枪身照旧可见；
**4 倍瞄准镜**：视野 ×1/4，**不铺整屏遮罩**（r83）——枪身与镜环照旧渲染，只叠十字分划
（r92 起抵肩还会隐藏原版准星，与 TaCZ 的 `show_crosshair = false` 一致）。
两种瞄具的光轴参照点写死在 `weapon/WeaponMount.java`，举枪时会自动顶到屏幕正中。

**AWP 栓动狙击枪（r79 新增）**：

- **模型**：取自参考包 `模型/AWP_Printstream_Minecraft`，由 `tools/awp_gen.py` 转成本项目坐标系
  （13 骨骼 / 58 方块 / 348 四边面，512² 逐面 UV，密度 19 像素每单位）—— 枪口 = `-Z`、
  上 = `+Y`、原点 = 机匣中心、握把（`move` 骨骼）在 `(0, -1.07, 1.31)`。
  骨骼：`root → move → body → barrel → bipod / scope → scope_adjust / scope_elev / scope_wind / magazine / bolt / trigger / casing`
- **8 倍镜（★ r91/r94 改实现）**：按住右键**直接进十字弩那套整屏镜筒开镜**（枪与手臂一起藏掉，
  镜筒外近黑 + 镜缘暗角 + 镜内分划 + **蓝色镜圈**），看镜时枪模走 TaCZ `scope_standard_8x` 的
  `views_fov = 20` 语义、举枪时枪模投影 FOV = **35**（TaCZ `ai_awp_display.json` 的 `zoom_model_fov`）。
  r83~r90 那种「枪与手臂一起抬起来、看得见枪与八棱镜环」的写法已按用户要求回退成镜筒遮罩；
  后坐也从「整枪平抬」改成**绕手的俯仰**（枪管微抬 + 枪托微沉，`WeaponHandGrip.AWP_FIRE_PITCH`）。
- **栓动**：只有膛内有弹才能击发（`HlcChamber`）；击发后**顿 6 帧（`BOLT_DELAY`）右手还在握把上扣扳机**，
  再拉栓：拉机柄抬起 **88°**（r83）→ 枪机后退 **3.4 像素** → 弹壳被抽壳挺顶出、边翻边向右上方抛飞
  （整条抛壳轨迹由 `boltProgress` 算出来，肉眼和读条永远对得上）→ 推回闭锁时自动上下一发
- **第一人称双手**（`client/WeaponArms.renderAwp` + `client/AwpGeoModel`）：右手平时握把、拉栓时抬起来
  抓拉机柄（与枪机共用同一份抬升/后退数学）；左手平时托在护木下方，只在换弹时伸过去拆/装弹匣
- **音效**：枪声 `模型/awp枪声.ogg`、换弹 `模型/AWP狙击步枪换弹音效.ogg`、拉栓上膛 `模型/拉栓上膛.ogg`
  （拉栓那一条与 AKM 共用；AWP 的那一声比枪声晚 6 帧响，对应「先扣扳机、再抬手拉栓」）
- 离线校核工具：`tools/_awpfp.py`（按原版手持变换链从眼睛透视渲染）、`tools/_awp_arms.py`（手到肩距离 / 拉伸倍率）、
  `tools/_awpscan.py`（扫 display / move 旋转 ↔ 屏幕倾角）、`tools/_awpanim.py`（把动画烘成静态姿态出预览图）、
  `tools/_oggdur.py`（不装第三方库读 Ogg 时长）、`tools/install_awp_sounds.py`

**弹道规则**：弹头在有效射程内几乎平直；飞越有效射程后，每 tick 追加的下坠量按「超出比例的平方」增长（约 2.25 倍射程后封顶）——想打得准，就得把目标留在有效距离之内。实现见 `weapon/Ballistics.java`。

**修复说明（r15）**：换弹/检视动画直接读取原版手持物品的姿态参数驱动，AKM 现在垂直握在手中而不再斜挂，弩与弓的拉弦姿态也与持握模型对齐。

## 弹药与弹药盒

弹药本身：

- `弩箭`（crossbow_bolt）— 十字弩弹
- `复合弓箭`（compound_arrow）— 复合弓弹，另有 `尸毒箭`（poison_arrow）变体
- `7.62x39mm 子弹`（ammo_762）— AKM 弹
- `.338 狙击弹`（ammo_338）— AWP 弹，与 7.62 **不通用**（`AmmoType.SNIPER`）
- **`7.62x59mm 子弹`**（`ammo_762_59`）— **莫辛-纳甘 M91/30** 弹，与 7.62x39、.338 **都不通用**（`AmmoType.MOSIN`）

**弹药盒**（r13 起区分多类，右键收纳背包中同类弹药，装填时优先从盒内取用）：

- `弩箭弹药盒` — 只吃弩箭
- `箭矢弹药盒` — 只吃复合弓箭
- `步枪弹药盒` — 只吃 7.62 子弹
- `.338 弹药盒` — 只吃 .338 狙击弹（容量 120，快捷栏 HUD 占第 4 个格子）
- **`7.62x59mm 弹药盒`** — 只吃 7.62x59mm 子弹（容量 **150**，快捷栏 HUD 占第 5 个格子）
- `创造弹药箱` — **放在物品栏（快捷栏 / 背包 / 副手）里就生效**：六把武器无限供弹，不用手持、不用切弹种

各类弹药盒虽然外观相似，但**合成配方互不相同**（中心格放对应的弹药本体），物品也是独立注册 ID + 各自 `AmmoType`，因此绝不混用。

## 投掷物：碎片手雷与震爆弹

两枚手雷共用一套拔销机制（`GrenadeItem` + `GrenadeEntity`）：

1. **按住右键 1 秒**拔出保险销；中途松手 → 保险销自动弹回，完全安全；
2. 拔销后引信 5 秒倒计时（HUD 实时显示）；压杆还被手压着时，**再按住右键 1 秒可把保险销插回去拆雷**；
3. **左键丢出**，出手瞬间压杆/击针自然脱落，落地滚动后爆炸；
4. 攥在手里超过 5 秒 → **掌心自爆**。

| 手雷 | 效果 |
|---|---|
| 碎片手雷 | 范围约 6.5 格的原版爆炸（威力 3.5，TNT 为 4.0），破片伤害；方块破坏跟随 `mobGriefing` 规则 |
| 震爆弹 | 半径 9 格内生物 **眩晕 + 致盲** 数秒，基本不造成伤害；隔不透明方块效果大幅衰减 |

## 六相月灾系统

夜晚月相按周期轮转（`moon/MoonPhase.java`），六种灾月各自有**专属的月亮颜色与天空颜色**，效果也不同：

> **r75 起月相是随机的**：每夜独立掷骰（基础 25%，六相同权重），不是固定轮转 ——
> 可能连着两夜同一个月相，也可能连着十几夜一个都不出。要手动调用就用
> `/hexalunar moon set <blood_moon|blue_moon|yellow_moon|super_blood|super_blue|super_yellow|none>`
> （`/hlc` 是简写；OP 2 级），`/hexalunar moon info` 看当前状态与概率。

| 月相 | 月亮颜色 | 天空（天顶 / 地平线） | 效果 |
|---|---|---|---|
| 血月 | 红 `#FF4A38` | `#1C0608` / `#521114` | **四波尸潮 + 亡灵随时间进化 + 不能睡觉** |
| 蓝月 | 淡青蓝 `#AECBFF` | `#06101F` / `#143A6E` | **玩家获得幸运 I（僵尸没有任何加成）** |
| 黄月 | 金 `#FFD35E` | `#141005` / `#453512` | **作物加速生长** |
| 超级血月 | 亮红 `#FF6E52` + 大光晕 | `#28070B` / `#6E1616` | **四波尸潮 ×1.5 + 进化更快 + 不能睡觉** |
| 超级蓝月 | 冰蓝 `#D2E8FF` + 大光晕 | `#08142E` / `#1C4A88` | **玩家获得幸运 II** |
| 超级黄月 | 淡金 `#FFE9A0` + 大光晕 | `#1C1608` / `#57431A` | **作物生长更快 + 空投巨箭** |

月升时全服弹出标题与提示，天空与月盘同时换上该相的颜色（实现在 `client/MoonSkyRenderer.java`，

## 变异亡者

月夜刷新的 6 种变异怪（`entity/mob/`）：

- **自爆尸** Bomber Zombie — 贴脸引爆
- **喷吐尸** Archer Zombie — 远程喷吐尸毒箭

- **巨尸** Giant Zombie — 巨型体型、重击退

- **剧毒骷髅** Toxic Skeleton — 射出带尸毒的箭

## 解毒与尸毒

- **尸毒**（Corpse Poison）：被变异亡者击中概率感染，持续掉血；
- **尸毒萃取剂**：从剧毒骷髅/喷吐尸掉落；
- **尸毒瓶**：尸毒萃取剂 + 玻璃瓶 → 2 瓶，投掷后在落点炸开一团尸毒雾；
- **强效解毒剂**：萃取剂 + 蜂蜜瓶 + 糖 合成，饮用清除尸毒。

## 操作一览

| 按键 | 功能 |
|---|---|
| 右键（按住） | 弓：蓄力瞄准 / 弩：开 4 倍镜 / AKM：据枪瞄准 / **AWP：抵肩开 8 倍镜** / 手雷：拔销或插回保险销 |
| 左键 | 射击 / 丢出手雷（**AWP：每发后自动拉栓抛壳，约 1.4 秒一发**） |
| `R` | 装填（AKM 换弹 / 十字弩上弦 / **AWP 换弹匣**）—— 可在 设置 → 按键绑定 → 六相月灾 中修改 |
| 潜行 + 右键 | **AKM：装/拆瞄具**（副手拿瞄具 = 装上，空手 = 拆下）；**手雷：把保险销插回去**（1 秒） |

## 安装

1. 安装 Minecraft 1.20.1 + Forge 47.x（推荐 47.4.0）；
2. 把 **GeckoLib 4.8.4**（`geckolib-forge-1.20.1-4.8.4.jar`）和 `hexalunar_calamity-1.0.0-r110.jar` 一起放进 `.minecraft/mods/`；
3. 启动游戏，选择 Forge 1.20.1 实例即可（**缺 GeckoLib 会直接加载失败**）。

从旧版本升级时直接替换 jar 即可，无需删世界数据。
