# AWP Printstream 风格 Minecraft 模型包

根据参考图（CS:GO/CS2 AWP | Printstream 皮肤）制作的多边形（立方体面片）模型，共 31 个立方体 / 186 个四边形面，含换弹骨骼与可调节 8 倍镜骨骼。

## 文件清单

| 文件 | 用途 |
|---|---|
| awp_printstream.bbmodel | Blockbench 工程文件，直接打开即可编辑/导出 |
| awp_printstream.png | 128×128 贴图（Printstream 白底黑纹风格） |
| bedrock/geometry.awp_printstream.json | 基岩版几何模型（带骨骼分组） |
| bedrock/animation.awp_printstream.reload.json | 换弹动画（弹匣下落 + 枪栓后拉） |
| bedrock/animation.awp_printstream.scope_adjust.json | 8 倍镜调节动画（变倍环/侧调焦钮旋转） |
| bedrock/animation.awp_printstream.scope_ads.json | 开镜瞄准动画（镜身下沉俯仰） |
| java/awp_printstream.json | Java 版物品模型（assets/models/item/ 下使用） |

## 骨骼结构（换弹 + 瞄具调节）

```
bone_body            机匣/枪托/握把（根骨骼）
├─ bone_barrel       枪管/枪口制退器
│  └─ bone_bipod     折叠两脚架
├─ bone_scope        8 倍镜整体（镜筒/物镜/目镜/镜座）
│  └─ bone_scope_adjust  可调节部件（变倍环 + 侧调焦钮，旋转即"调节倍率"）
├─ bone_magazine     弹匣 —— 换弹骨骼（下移拆装弹匣）
└─ bone_bolt         枪栓 —— 换弹骨骼（后拉上膛）
```

- 换弹：播放 `animation.awp_printstream.reload`，弹匣先下落 5 像素再装回，枪栓随后后拉 2.5 像素复位，总时长 2.2 秒。
- 8 倍镜调节：`bone_scope_adjust` 独立成骨，播放 `scope_adjust` 动画时变倍环与侧调焦钮沿镜筒轴旋转 720°；在 Blockbench 中也可直接手动旋转该骨骼做静态档位。
- 开镜：`scope_ads` 让镜身轻微下沉并俯仰 -8°，模拟举镜瞄准。

## 使用方法

### Blockbench（推荐）
1. 打开 Blockbench → File → Open Model → 选择 `awp_printstream.bbmodel`（贴图已内嵌）。
2. 在 Outliner 中可看到上述骨骼分组，直接调整骨骼旋转/位移即可做姿态或新动画。
3. 导出：基岩版选 Format "Bedrock Model" 导出几何；Java 版选 "Java Item/Block" 导出。

### 基岩版（Add-on / 资源包）
1. 将 `geometry.awp_printstream.json` 放入资源包 `models/entity/`（或物品用 `models/`）。
2. 动画文件放入 `animations/`，并在资源包 `manifest.json` 与物品/实体定义中引用：
   - `"geometry": {"identifier": "geometry.awp_printstream", ...}`
   - `"animations": {"reload": "animation.awp_printstream.reload", ...}`
3. 贴图 `awp_printstream.png` 放入 `textures/` 并在材质中引用。

### Java 版
1. `java/awp_printstream.json` 放入资源包 `assets/<命名空间>/models/item/`。
2. 贴图改名为 `awp_printstream.png` 放入 `assets/<命名空间>/textures/item/`。
3. Java 版物品模型不支持骨骼动画，换弹/调节动画仅基岩版或通过 Blockbench 另做实体模型使用。

## 坐标约定
X = 枪口朝前，Y = 上，Z = 横向；单位像素（16 像素 = 1 格）。枪管长约 18 像素，符合手持物品显示比例（display 中已设 0.5 倍缩放）。
